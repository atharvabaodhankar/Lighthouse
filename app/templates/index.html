Android Private DNS (Encrypted DNS-over-TLS)

Protects your phone everywhere: on home Wi-Fi, 4G/5G mobile data, and public Wi-Fi networks.

Recommended for Mobile
1
Open Android Network Settings
Open Settings → Network & internet (or Connections → More connection settings on Samsung Galaxy).
2
Select Private DNS
Tap Private DNS, then choose the option Private DNS provider hostname.
3
Enter Lighthouse Hostname
Paste the TLS-secured hostname and tap Save:
3-111-211-129.sslip.io
4
Verification
Android will immediately validate the TLS handshake on port 853. Open any browser and notice ads, banners, and telemetry vanish!

iPhone & iPad (iOS 14+) Setup

Configure DNS manually for your home Wi-Fi network, or install a DoT configuration profile.

iOS Wi-Fi DNS
1
Open Wi-Fi Settings
Go to Settings → Wi-Fi. Tap the blue (i) info button next to your active network name.
2
Configure DNS to Manual
Scroll down to Configure DNS. Change the setting from Automatic to Manual.
3
Add Lighthouse DNS Server
Delete existing entries and tap Add Server. Enter:
3.111.211.129
Optionally tap Add Server again and enter 1.1.1.1 as backup. Tap Save in the upper right.

Windows 11 / 10 Configuration

Set DNS via Windows Settings or run a one-line PowerShell command.

Windows
⚡
Fast Setup: PowerShell (Run as Administrator)
Open PowerShell as Admin and execute:
Set-DnsClientServerAddress -InterfaceAlias "Wi-Fi" -ServerAddresses ("3.111.211.129","1.1.1.1")
2
Manual Settings Path
Open Settings → Network & internet → Wi-Fi → Hardware properties → Under DNS server assignment click Edit → Set to Manual → Enable IPv4 → Preferred DNS: 3.111.211.129.

macOS Configuration

Quick Terminal one-liner or System Settings procedure.

macOS
⚡
Terminal One-Liner
Open Terminal and run:
sudo networksetup -setdnsservers Wi-Fi 3.111.211.129 1.1.1.1
2
System Settings Method
Go to Apple Menu → System Settings → Network → Wi-Fi → Details... → DNS tab → Click + → Add 3.111.211.129 → Click OK.
Verify DNS Ad Sinkholing in Terminal
Test that tracker domains resolve to 0.0.0.0:
nslookup doubleclick.net 3.111.211.129
